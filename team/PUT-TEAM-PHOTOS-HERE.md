# Team photos go in this folder

- Square photos work best (about 600 × 600 px), JPG or PNG.
- File names: small letters, no spaces, e.g. `julie.jpg`, `riad-tawil.png`.
- Then open `team.js` (one folder up) and set that person's `photo` to `"team/julie.jpg"`.

To upload: open this folder on GitHub → **Add file** → **Upload files** → drag the photo in → **Commit changes**.
